# Program verification

This suite contains 18 independent Python programs for TI-84 Evo calculation checks.

## Checks included

- Numerical examples and adverse input cases.
- Unit conversion, impedance-base and circuit-topology checks.
- Battery duty sections, CT burden, bus heat balance and reactor calculations.
- ASCII source, calculator filename lengths and standalone imports.
- Matching input/output examples in the instruction manual.

Run the commands in the [program guide](./TI84_HV_TOOLS/README.md#desktop-verification) to check your copy.

## Before use

Confirm the input units, operating configuration and applicable equipment data. An output marked MEETS applies only to the entered values and stated calculation model. On a numerical or input error, discard the run and restart.

Physical execution on your calculator firmware should be checked with the manual's examples before routine use. Engineering equipment selection and operation require the applicable study and approval.

See the [instruction manual](./TI84_HV_TOOLS/INSTRUCTION_MANUAL.md) for inputs, examples and limitations.
